# §19 个人账号电脑中转（2026-10-23）

用户确认使用个人 CLI 登录调用 DeepSeek V4.1 Flash；不回退 GLM 或直付 API。

- 手机仍在本机保存衣橱、照片和批量草稿。识别请求沿用原有裁剪图 + 原图 + 归一化选区、词表归一化、冲突留空和逐件确认契约。
- 电脑运行 `scripts/desktop_bridge.py`，使用官方个人 CLI 的正常登录。模型固定 `deepseek-v4.1-flash`，关闭工具、MCP、项目设置和会话保存。凭证不读取、不传入手机。
- 中转仅接受带随机配对码的请求，单次至多两张内嵌图片，限制请求大小，并发繁忙立即返回，不自动重试。原图不落电脑文件或日志。收包最多10秒，推理最多75秒；手机等待90秒，页面等待100秒。
- 手机通过「服务状态 → 电脑识别设置」配置局域网地址和配对码。连接测试只验证中转与 CLI 可执行文件，不发推理、不声称积分免费或登录仍有效。保存至应用私有数据目录的独立配置文件，原子替换，不改衣橱表和草稿。
- 配置中转后，识别和搭配模型均走中转。中转离线、配对错误、CLI 登录失效、积分不足、超时分别返回安全错误；不会切回直付接口。已填属性、裁剪和待入库照片保留。
- 地址限制为明确的局域网 IPv4 或回环地址，禁用代理及重定向。连接码不从 GET /health 或配置读取接口返回。
- 电脑中转不会随 APK 自启动；电脑须开机并启动中转，手机和电脑同网。USB reverse 可作受限网络下的调试通道，不能宣称 Wi-Fi 已验证。

文件分工：`scripts/desktop_bridge.py` 执行官方 CLI；`app/services/llm/desktop.py` 管理手机配置和请求；客户端工厂与 readiness 接入桥接；meta 路由管理连接；前端设置弹层和安全错误提示。主 agent 唯一写入，两路只读审查分别负责后端执行/认证与前端状态/产物。

验证：隔离临时目录的认证、输入、并发、超时、配置和无回退测试；全量 pytest、83 项 smoke、三视口 UI 与对比度门禁；合成双图真实调用；真机覆盖安装前后衣橱数量和草稿哈希对比；APK 静态资源与源码逐字节核对。用户商品原图不导出。

## §29.1 完整结果与CLI退出收尾超时

本机官方CLI源码表明，完整result输出后仍可能等待内部响应流结束、输出排空与退出收尾；旧实现subprocess.run超时便丢弃stdout。当前正常返回与超时共用解析路径：超时仅在init的个人来源/固定模型正确、最后完整result为success、is_error严格false、非空限长且无cancelled/is_cancelled或terminal_reason=aborted_streaming/aborted_tools时复用结果。缺失、截断、错误来源/模型及取消终态继续504；不凭assistant片段成功，不重发请求，不改变75秒及手机等待上限。

日志仅记录本地产生request_id、耗时与before_init/awaiting_result/incomplete_result/result_received_exit_pending/completed阶段，不含提示、图片、原始输出或凭证。新增合成超时回归覆盖完整结果、错误init、取消、截断和后续失败。该修复解决有完整结果但退出慢的路径，不能宣称所有供应商超时已经消除，旧草稿失败原因无法追溯。
