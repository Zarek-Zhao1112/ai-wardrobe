# 页面与交互说明

本文按当前前端源码记录可见页面和交互入口。动态结果取决于本地衣橱与任务状态，预览样例应展示明确标注的演示数据。实现调整后同步更新。

文中「交互预览」一律指从工作台本地服务地址打开的界面（双击 `启动效果图.bat`，或见 [README](README.md) 的打开方式）。直接双击 `index.html` 只能看截图。

## 主导航

### 今日 #today

- **用途**：展示今日穿搭入口、风格灵感、最近搭配和已想要的添置单品。
- **主要操作**：打开风格详情；从风格详情按此风格进入「搭配」；打开最近记录查看详情。
- **会打开的界面**：风格说明面板、搭配或添置记录详情对话框。
- **返回路径**：关闭面板或详情后回到今日页原位置。

### 搭配 #outfits

- **用途**：浏览审美方案和搭配结果。
- **主要操作**：左右切换审美方案；打开审美说明面板；发起生成；查看某套搭配依据；提交喜欢、不喜欢或暂不选择反馈；打开实时试衣。
- **会打开的界面**：审美指南、生成设置、搭配依据、完整审美方案和实时试衣面板。具体面板内容由入口和当时的任务状态决定。
- **关联页面**：从单品详情进入时可带入必选衣物；关闭详情后回到原先页面。
- **返回路径**：关闭面板或试衣界面回到当前搭配位置；任务中操作应保留任务状态。

### 添置 #gaps

- **用途**：查看审美方向、AI 添置建议、选购参考和已想要清单。
- **主要操作**：打开添置助手；选择衣橱单品与建议方向；补充偏好；查看分析进度；打开款式参考；查看选购要点；标记「我想要」或换个方向；查看、删除或回看已保存记录。
- **会打开的界面**：添置助手的多个步骤、待分析与分析中状态、分析结果、款式参考详情、选购要点、任务查询和已想要清单。
- **返回路径**：助手面板可返回上一步或关闭；款式与选购详情关闭后回到来源卡片。进行中的请求按原任务标识查询。

### 衣橱 #wardrobe

- **用途**：浏览和筛选已录入单品。
- **主要操作**：搜索名称、品牌或备注；按槽位与品类筛选；显示已归档衣物；加载更多；录入新衣物；打开单品详情。
- **会打开的界面**：筛选对话框、单品玻璃详情面板和录入面板。
- **返回路径**：关闭详情或筛选后回到衣橱列表，并恢复原列表位置与筛选条件。

## 隐藏路由与浮层

### 录入衣物 #add

- **入口**：衣橱页的录入按钮。
- **面板内容**：只有照片入口（拍照 / 相册两个按钮）。2026-11-17 起这里不再挂属性表单 —— 名称、品类、主色、材质都在下一步的逐件确认页改。
- **阶段**：添加或追加照片、逐件确认、查看 AI 整理的信息、翻回照片、保存并继续、保存并结束、跳过单件、重试失败保存。
- **属性修改**：逐件确认页的「衣物信息」面可改名称 / 品类 / 主色 / 材质；下面的「更多属性」折叠里还有版型、裤长、正式度、图案（下拉）与风格、季节、场合（多选）、品牌、备注。AI 认出来的值会先填好，人只改要改的。
- **工作台样例**：拍照和相册按钮会放入示例衣物。识别与平铺使用预设结果。保存后显示批次完成页，再进入衣橱可看到该演示单品。
- **返回路径**：完成、收起或取消后回衣橱。批次草稿与进度按现有前端持久化规则恢复。

### 单品详情 #item/{id}

- **入口**：衣橱列表单品，或搭配中选作必选衣物的单品。
- **显示方式**：全屏玻璃详情面板；可以展开全部搭配信息或翻转详情区域。
- **属性修改**：翻到「衣物信息」面，顶部有一颗「编辑衣物信息」按钮，点开是弹层：名称 / 品类 / 主色 / 材质 + 「更多属性」（版型、裤长、正式度、图案、风格、季节、场合、品牌、备注）。表单与逐件确认页共用同一份，保存时只提交真正改过的字段；保存后详情自动刷新，翻卡朝向和滚动位置不变。取消、点遮罩、按 Esc 都只关弹层，不会关掉整张详情。
- **关联跳转**：从单品进入搭配时，该单品作为必选衣物带入。
- **返回路径**：关闭后恢复进入前的页面与列表状态。

### 衣橱筛选

- **入口**：衣橱页筛选按钮。
- **操作**：选择品类、显示已归档，应用筛选或关闭。
- **状态**：筛选界面通过历史状态与页面路由恢复。

### 最近记录详情

- **入口**：今日页的最近搭配或已想要卡片。
- **内容**：记录摘要、搭配衣物、添置方向或关联状态。
- **返回路径**：关闭后回今日页。

### 添置相关面板

- **添置助手**：从添置主页面进入，可浏览选衣、选择方向、补充偏好、准备和分析等阶段。
- **任务查询**：用于查看已有任务的进度与可确认结果；查询沿用原任务编号。
- **款式参考**：从建议卡查看对应 AI 款式示意或商品参考。
- **选购要点**：展示方向说明、颜色、版型、外观、现有衣物搭配、注意事项以及「我想要」操作。
- **已想要清单**：从添置页入口打开，可查看并取消已保存的方向。

### 实时试衣

- **入口**：搭配相关操作。
- **初始状态**：摄像头未开启，说明需要用户主动开启。
- **操作**：开启摄像头、切换前后摄像头、换一套、停止、查看原始画面或关闭。
- **状态说明**：当前项目提供摄像头预览，页面说明不可将其表述为生成式实时换装。
- **工作台样例**：开启按钮播放标有「工作台演示画面」的本地图片流，可以切换参考衣物、停止或关闭。

## 设置 · AI 通道

- **入口**：点击 App 右上角的设置齿轮，在「服务状态」下查看「AI 通道」。
- **默认通道**：新安装使用 API 直连。点 API 设置进入 OpenAI 或 DeepSeek 的配置面板。
- **切换方式**：AI 通道二选一 —— 「API 直连」（手机自己联网，用手机里存的 Key）或「电脑中转」（经电脑出网）。选了电脑中转后，下面多一组「电脑上游」：「账号额度」用电脑已登录账号的额度，「API 计费」让电脑直调自己的模型、按 OpenAI 用量付费。点一下即生效。
- **为什么手机上只能选电脑中转来用 API**：手机到 `api.openai.com` 是超时的，所以「用 API 但不花账号额度」只能由电脑代跑。
- **预览范围**：工作台使用 App 的设置界面和演示接口。请使用演示值，工作台无需真实 Key。
- **交互预览**：右上切到「交互预览」后，这一页是 App 的真实界面，可以直接点「API 直连 / 电脑中转」与「账号额度 / API 计费」，也可以在弹层外点一下关闭。地址为 `?mode=live#model-channel`，刷新后仍停在交互模式。

## 设置 · 选择模型

- **入口**：从齿轮菜单点击「API 设置」，或从工作台左侧点击「设置 · 选择模型」。
- **操作**：切换服务商后，「模型」自动选中该服务商唯一的那一档高能力模型。文字分析和衣物照片识别共用这个模型，不再分别选择，也没有「暂不启用图片识别」这个选项。
- **下一步与返回**：保存后回到 AI 通道菜单。关闭面板可放弃本次修改。工作台的 Key 栏为演示状态，保存只影响当前预览服务。
- **模型选项**：OpenAI 使用 GPT-6 Luna，API 型号为 `gpt-6-luna`。DeepSeek 使用 V4.1 Flash，API 型号为 `deepseek-flash`。两家都只有一档，都是高能力模型，文字和图片输入通用；工作台使用演示响应。 [OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6-luna) · [DeepSeek 模型文档](https://api-docs.deepseek.com/quick_start/pricing/)
- **强度**：不分档，两家都按高强度思考请求（OpenAI `reasoning_effort=high`；DeepSeek `thinking.enabled` + `reasoning_effort=high`）。界面上没有强度选项，也不用选。实测同一张 797KB 照片打标 5.6 秒、思考占 84 token，比关掉思考只多 2 秒。详见 `docs/design/ui-contract.md` §61。
- **交互预览**：切到「交互预览」后可以真的操作——换服务商，「模型」会跟着换；点「保存并使用 API 直连」会走演示接口并回到 AI 通道菜单。地址为 `?mode=live#ai-models`。
