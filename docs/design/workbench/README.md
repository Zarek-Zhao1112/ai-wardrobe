# AI 衣橱设计工作台

已确认的设计范围与讨论约定见 [设计约定](设计约定.md)。
当前页面及其交互路径见 [页面说明](页面说明.md)。

在项目根目录运行以下命令。关闭终端或按 Ctrl+C 可停止预览。

```powershell
.venv/Scripts/python.exe docs/design/workbench/serve.py --open
```

- 顶部提供「界面截图」和「交互预览」两种查看方式。截图来自项目当前前端，视口为 393 × 819。交互预览加载项目原来的 HTML、CSS 和 JavaScript。
- 交互预览使用六件初始示例衣物和预设结果。可以查看搭配结果、查询添置任务、走完示例照片录入，或在试衣面板查看标记过的演示画面。预览服务重启后会重置演示数据。
- 真实衣橱、摄像头和 AI 接口与工作台隔离。较少见的错误分支见页面说明。
- 左侧可以切换四个主页面及其已截取的交互状态，并查看逐页说明。
- 每张图配有入口、操作及返回路径说明。右侧备注按界面保存在当前浏览器。固定使用同一个网址和端口即可回看。
- 衣物来自仓库示例图。搭配与添置结果使用演示接口响应。效果图本身是静态截图，可以用左侧目录查看不同状态。
- 项目前端或交互变更后，重新截取对应界面并更新说明。讨论确认的设计变更再应用到 App。
- 需要比较旧稿时，在 screens 文件夹里按版本保存截图，并在页面说明中标记版本日期。
