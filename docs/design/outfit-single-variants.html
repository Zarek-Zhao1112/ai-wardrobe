为什么能快

  • 慢的根源是输入，不是输出：只把 limit 从 3 改成 1，输入 prompt 一字不变（实测两次都是 4921 字符）。
  • 所以要让模型只看到选中的那一套：本地按「五维评估 × 85% + 个人偏好 × 15%」排出名次，取前 5 随机挑 1 套。
  • 模型保留唯一不可替代的活：把这套的颜色、品类、材质翻译成一句人话。
  • 注意 时间没法实测 —— DeepSeek 账户 402 余额不足，改完只能报 token 降幅。

不动的部分

  • 堆叠、拖拽、露边的代码全部保留：只剩 1 张卡时 deck.length < 2 自然短路，将来想恢复多套改回 limit 即可。
  • 第一层「一屏一张审美卡」不变；「认识这个」详情、试衣、搭配依据、反馈全不变。
