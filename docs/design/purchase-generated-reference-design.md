# §38 添置使用 AI 款式示意

用户暂停真实商品图搜索，改用AI生成选购方向示意。现行六审美、衣橱分析、B玻璃助手、前置配图与勾选后复用图片保持；不开放第二种图片来源选项。新图为纯白底、居中完整单品、无模特或营销文字，不虚构品牌、商品链接、价格和在售状态。标为“AI款式示意”，已有真实商品照片仍按原来源展示。

DeepSeek调度/分析模型与现有账号不变。新增官方CLI文生图能力hunyuan-image-alpha；录入平铺编辑继续hunyuan-image-alpha-edit。独立style/jobs端点与状态目录复用现有幂等队列，一方向一次固定ImageGen调用，排队共享CLI锁；超时或重启只查询原任务，不自动换模型或重新生成。Hook严格锁定文本、尺寸和输出目录，禁止参考图片与其他参数。服务能力通过health单独声明。

新分析/方向/任务记录明确image_origin=generated；图片行origin=generated且没有source_url。手机与电脑按来源隔离缓存签名和任务目录，复制引用继续校验规格、来源、归属与摘要。旧任务、草稿、收藏和原始商品来源不改写；不自动将历史失败任务转换为收费生图。手机同类任务的提交串行，避免多方向同时抢占中转接单锁。

生成图片仍校验类型、上限、摘要与本机解码；全部未知/失败/缺图状态保留上次完整结果。提示“生成款式示意/整理建议”，不再把新任务描述成寻找商品图。提供方实际输出的必要生成标识保持，不通过裁剪抹除；产品层展示AI示意标签。schema、衣橱与账号配置保持。

验证覆盖新图无URL、伪来源拒绝、跨来源缓存隔离、旧引用兼容、同ID不换源、排队、重启/未知只查、勾选零额外生成、失败保留旧结果、真实UI文案与离线资源。两路只读审查；实际生图只做明确有界的连通与质量验证，额外流程使用假服务。发布需更新资源清单与SW，解包核对APK与真机保留数据。
