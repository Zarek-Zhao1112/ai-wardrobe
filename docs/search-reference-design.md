# §31 自动寻找实物参考与搭配触控（2026-10-28）

> 添置展示与首次补图流程现以§32为准，§31的独立找图和无图文字卡已取消。

用户确认purchase-search-interaction-preview和outfit-touch-interaction-preview，授权实现。唯一写入方为主agent，两位只读审查按后端来源/任务与前端交互/生命周期拆分。DS4.1、现有个人账号和生图模型不变。

## 实物参考

- 新推荐POST成功先保存文字方向，然后为各方向登记独立搜索任务，页面先显示文字。旧结果、GET、回看和重启只读，不自动补收费任务；旧记录用户可点“找实物参考”。只重找照片不重做推荐。
- 官方个人CLI的WebSearch是text2text，非图片搜索。仅允许本次固定query的一次WebSearch，关闭其他工具/MCP/项目设置/会话保存；独占hook防止第二次工具执行。来源取实际tool_use关联的tool_result._meta.rawResponse，不信模型最终回答的图片网址。
- 按网页实际Product JSON-LD、明确的商品页og:image及与商品标题/主图标记关联的可见图片提取候选；轮流查看各页前三个角度，最多核对六张。限制重定向、响应体积、公开DNS和连接IP，拒绝内网、凭据、非标准端口与非图像内容。最终每页最多一张、最多三个不同图片内容。
- 下载前排除分享海报/opengraph等图片路径，下载后复核实际地址、尺寸和比例。DS4.1必须逐张确认单件衣物、无人、无价格和营销文字、外观符合方向；四项均明确为true才选用，同一ID重复或判断矛盾则排除。不确定留空，不更改方向迁就图片；成分/触感未知不能臆断，也不据此否决可见外观参考。
- 不依赖固定本地图库。实际选中照片验证类型/大小/摘要后缓存到手机；详情一主图、最多两张备选、点击和横滑选图、明确来源。匹配少于三张按实际数量显示；找不到保留文字并可显式重试，失败保留旧照片。
- 推荐方向、用户/plan/direction、查询任务UUID绑定；POST稳定幂等；未知提交只GET查询，不自动重发。独立queued/running/unknown/complete/empty/failed/interrupted状态。手机/电脑重启不重放收费任务；电脑内同类任务串行，网络取图期间不占用普通识别CLI锁。
- 搜索输入仅添置方向，不包含原衣橱图片、衣物ID或账号凭证。错误不向手机暴露CLI/网页原文。图片是款式参考，无价格、商家筛选或代购操作。
- 不新增数据库表/迁移，记录存现有meta、照片缓存存私有images。复用现有配对电脑，无新增API密钥设置。缓存照片与用户衣物分开命名，不改变原图/平铺图。

## 搭配触控

- 只有图片区域接收横向换套，纵向保持原生滚动；10px后锁轴，横向超过50px才换套。短横拖、纵拖、停顿、移出与取消均不误开单品；滑动后拦截兼容click。
- 保持每件图片独立网格、不遮挡；衣物和说明同步切换，圆点与“换一套”仍可点，减少动态效果时直接切换。
- 单击真实单品沿用现有玻璃详情与返回；试衣面板仍只提供已实现的真实摄像头预览，未配置视频AI时不显示假结果。
- 切页释放手势/动画监听，生成失败保留已有结果，旧试衣deck不写入新deck；搜图状态更新不重绘已打开玻璃层的背景表单或篡改返回历史。

## 验收

用隔离库/假CLI验证幂等、未知结果/重启不收费、来源链、SSRF与照片哈希、推荐失败保留、用户边界；真Chrome四宽度验证实际横拖/纵拖/短停、单品详情返回、多图切换与异步状态、底栏和44px触控。真机只读验证已有数据，不以旧批次/旧推荐发起付费验收。APK解包逐文件对照、手机数据哈希核对、原回归/对比度/UI门禁和两路审查后安装。

## §32 每条添置建议必配实物商品图（2026-10-28，用户确认新预览）

- 点击AI推荐自动分析、搜图、核对。各方向图文配齐才成为可点开的正式建议卡；已配好一条就展示一条。缺图仅显示准备/失败状态，不泄露该方向正文，不提供纯文字、生成图或图库选项。
- 可见旧结果和已记下页自动POST `/wardrobe/purchase/references/ensure`（plan_id）；初始页不补图。GET保持只读。服务端验证当前用户最新/已记下plan，在锁内复用已登记的任意状态；只有从未登记的方向才用稳定UUID创建首次任务。重挂、并发、新推荐自动链与补齐不会重放已有失败/未知任务。
- 失败/空/中断只保留“重试”；显式重试沿用原单方向接口。已合格图继续显示和复用，成功详情无独立找图按钮。图片读取失败时剔除该照片，其他备选可用则保留；没有可用图片时撤下该卡，关闭已打开详情并恢复重试状态。
- 首次补齐响应未知先GET读取已登记任务；不会自动提交另一轮搜索。卸载取消客户端轮询和通知，已提交服务端任务仍可继续；返回初始页不被迟到结果拉回。
- 使用原DS4.1与当前账号、不变更生图模型/schema、手机衣物/草稿。四宽度真实前端、合成任务并发/失败/断网/重挂与APK解包核对后覆盖安装。
